# Interactive Explainers

Step-by-step, tap-to-learn web explainers. Plain static HTML/CSS/JS with no build step.

- [`electrical/`](electrical/): how a home electrical system works
- [`engine/`](engine/): how a 4-stroke internal combustion engine works (gas vs diesel)

Open `index.html` locally, or view it on GitHub Pages. Use the arrow keys or the Next/Back buttons.
